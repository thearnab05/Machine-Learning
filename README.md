# Machine Learning Project

This repository contains my Machine Learning project files and experiments, focusing on foundational algorithms built from scratch.

## Current Implementations

- **Linear Regression (`linear_regression.py`)**: A from-scratch implementation of Linear Regression using Gradient Descent. Includes synthetic data generation to test and verify the model's learned weights and biases against expected values.

## Dependencies

The project uses Python and relies on the following libraries:
- `numpy` (for matrix operations and synthetic data generation)
- `pandas` (for data manipulation and analysis)

## Setup

1. Clone the repository.
2. Ensure you have Python installed.
3. Install the required dependencies:
   ```bash
   pip install numpy pandas
   ```

## Running the Code

To test the Linear Regression model, simply run:
```bash
python linear_regression.py
```
